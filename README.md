# Outmake for Homebrew

[Outmake](https://outmake.app) runs open AI models on your Mac: chat, pictures, video, voices and dictation. Free, no account. Needs Apple silicon and macOS 26 or later.

```sh
brew install --cask outmakeapp/tap/outmake
```

Outmake updates itself. To remove it and everything it saved:

```sh
brew uninstall --zap --cask outmake
```
